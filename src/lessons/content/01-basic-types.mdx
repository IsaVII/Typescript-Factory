TypeScript is JavaScript plus **types**. A type describes what kind of value a variable can hold.
TypeScript checks your code _before_ it runs, then the types are removed and plain JavaScript runs.

## Type annotations

Add a type with a colon after the name:

```ts
let machineName: string = "Sawmill";
let outputPerTick: number = 2;

outputPerTick = "fast"; // ❌ Type 'string' is not assignable to type 'number'.
```

## Type inference

When you assign a value right away, TypeScript **infers** the type, so you usually don't need the annotation:

```ts
let outputPerTick = 2; // number
const machineName = "Sawmill"; // the literal type "Sawmill"
```

<Tip>
  Let TypeScript infer variable types, but **always annotate function
  parameters**. TypeScript can't guess what callers will pass in.
</Tip>

<Tip tone="warning">
  Avoid `any`: it switches type checking off for that value.
</Tip>
